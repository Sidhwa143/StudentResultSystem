STUDENT RESULT MANAGEMENT SYSTEM
================================

1. PROJECT DESCRIPTION
----------------------
The Student Result Management System is a web-based application used to manage student details, course information, marks, grades, and academic results.

2. TECHNOLOGIES USED
--------------------
Frontend: HTML, CSS, JavaScript
Backend: Node.js and Express.js
Database: PostgreSQL

3. MAIN FEATURES
----------------
- Administrator login
- Dashboard for managing academic records
- View and search student details
- Manage course information
- Add, update, view, and delete results
- Validate marks between 0 and 100
- Calculate and display SGPA

4. DATABASE
-----------
Database Name: student_result_db

Tables:
- admins
- students
- courses
- results

5. REQUIREMENTS
---------------
- Node.js and npm
- PostgreSQL
- Visual Studio Code
- Web browser

6. HOW TO RUN
-------------
1. Open the backend folder in the VS Code terminal.
2. Install dependencies using: npm install
3. Make sure PostgreSQL is running and the database connection details are correct.
4. Start the server using: node server.js
5. Open http://localhost:5000 in your browser.

7. CONCLUSION
-------------
This project provides an organized way to manage student academic records using web technologies and a relational database.
